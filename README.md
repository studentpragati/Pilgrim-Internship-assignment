# Finance Data Automation & Dashboard

### Project Overview
This project automates the reconciliation of bank statements and internal ledgers using **Django** and **Python**. It features a rules-based matching logic and a professional **Power BI** dashboard.

### Key Features
- **Task 1: Data Ingestion** - Handled via Django Admin for quick data entry.
- **Task 2: Reconciliation Logic** - Matches transactions with exact amounts and a 2-day date window.
- **Task 4: APIs** - REST endpoints for Summary (`/summary`) and Category Breakdown.
- **Task 5: Dashboard** - Visualized expense breakdown and status metrics in Power BI.

### Tech Stack
- Backend: Django, Python
- Database: SQLite
- Visualization: Power BI
